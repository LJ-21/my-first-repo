## Getting Started

1. **Clone the repository** — Run `git clone <repo-url>` to copy the project to your local machine.
2. **Install dependencies** — Navigate into the project folder and run `npm install` (or the relevant package manager command) to install required packages.
3. **Run the project** — Start the project with `npm start` and open your browser to `http://localhost:3000`.
